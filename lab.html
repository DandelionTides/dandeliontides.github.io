02 / Real Web API

GitHub 资料查询

点击后使用浏览器的 fetch() 获取公开数据，无需 API key。

准备好发出请求了吗？

GET api.github.com/users/dandeliontides

匿名请求有速率限制；如果失败，可以稍后重试。
